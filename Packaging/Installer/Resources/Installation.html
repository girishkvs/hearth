Get started

Hearth installs in Applications with a Terminal command and a small helper. Open the app and click its flame icon in the menu bar. Use hearth in Terminal, or hearth web for browser controls.

Permission and settings

Setup and maintenance need administrator approval; everyday controls do not. Installation leaves sleep settings unchanged.

Remove Hearth

Use the companion Hearth-Remove.pkg. Restore previous settings in Hearth first, if desired.

Locally built and unsigned; not notarized by Apple. Use only a package from a source you trust.
