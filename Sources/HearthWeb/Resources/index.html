    Setup or repair

    Run hearth setup for instructions. From source, build scripts/package-installer.sh, review the versioned package under dist/, then use scripts/install.sh --gui or --cli explicitly. This page never opens Installer or asks for a password.

    Use scripts/uninstall.sh --keep-settings --gui (or --cli) for explicit removal. Setup, repair, and updates may require administrator approval; everyday controls do not.

    Lock uses public current-user preferences; no Automation setup is needed. CLI and web use the verified Hearth app as one serialized current-user writer. Helper installation is separate and supports System/Display power changes.

    Hearth controls idle sleep only. Lid closure, manual sleep, critical battery, system safety behavior, and other apps' sleep assertions are unchanged.

    Manual lock, passwords, authentication, lid closure, and system safety behavior are unchanged. Closing this page keeps all settings.
